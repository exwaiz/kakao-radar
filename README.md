# 카톡 레이더 v1.0.0

Redmi Note 14 5G / Android 15의 KakaoTalk 알림 수집, HTTPS 동기화, 관심사 분석과 Telegram 요약 전달을 통합한 개인용 서비스다. Android와 서버 버전은 1.0.0이며 통합 브랜치는 master다.

**2026-09-18 테스트:** 한국 시간 매시 정각 1시간 간격, 최대 3개 관심 주제와 실제 원문 인용을 전달한다. 새 후보가 없으면 보내지 않는다. 9/19 자정에 기존 23:00 / 하루 1회 / 최대 5개 주제로 자동 복귀한다. 오늘 이미 사용한 발송 횟수를 보존하기 위해 기존 테스트 quota 144회는 유지하며, AI 예산은 하루 $1다.

방별 전달 진도와 원문 ID·내용 receipt로 새 대화 구간만 이어서 보고한다. 같은 원문 재노출 및 과거 후보 회귀를 억제하고 Telegram 제목·핵심 요점 bold, emoji, 실제 대사와 수집 시각을 표시한다. 프로필 버전, 문장별 근거, 작업 복구, 비용 예약·정산과 피드백을 지원한다.

실제 선택 방 업로드, OpenAI 분석 및 사용자 보고를 통한 Telegram 수신을 확인했다. 수집률·재부팅/야간 지속성·사용자 50주제 품질 평가·본폰 표시 지연 실측은 별도로 남는다. 현재 WSL과 노트북을 실행하고 USB reverse를 유지해야 한다.

## 구현한 기능

- 본폰 정기 요약 큐, 시간대/시간표·조용한 시간·일일 시도 상한, 요약/내용 중복 억제.
- Telegram 개인 채팅 및 ntfy HTTPS JSON 어댑터, 제한 재시도와 불명확한 결과 확인 대기, Worker 중단/소유권 복구.
- 요약 묶음에 한정된 링크로 전체 요점·URL·근거 조회, 유용함/관심 없음 피드백. [M4 실행·연결 안내](docs/M4_DELIVERY.md).

- 알림 접근 설정과 연결 상태 확인, 대상 방 발견·선택, 수집 시작·중지.
- 그룹 알림을 MessagingStyle → EXTRA_MESSAGES → 표준 텍스트 순으로 해석. 제목 대체는 명시적 그룹 표시와 shortcut ID가 함께 있을 때만 허용. 다른 앱·개인 대화·그룹 요약은 제외.
- Room DB에 원문·발신자 가명·시각·URL과 전송 대기열을 함께 저장. 대화 ID가 있으면 표시 제목 변경에도 같은 방으로 구분한다.
- HTTPS 서버 설정, Android Keystore 토큰 보관, WorkManager 네트워크 재시도·15분 주기 복구, 방별 전송.
- FastAPI 기기 인증·방 허용, PostgreSQL 이벤트 고유 키·항목별 결과, 원문 만료와 서버 방 삭제·차단.
- 버전이 있는 관심/제외 프로필, URL·시간·문맥 기반 주제 묶기, 정정 문맥과 문장별 근거 요약.
- PostgreSQL lease/소유권과 호출 재시도, 방들 사이에서 공유하는 일일 토큰·비용 예약, 실패/보류 상태 조회.
- 인증된 요약/근거 조회, 원문 만료 표시, 관심 재현율·후보 정밀도와 근거 검토 평가 도구.
- 이전 메시지 창의 HMAC 서명을 영속 저장해 알림 갱신 중복을 억제. 동일 문장의 반복 횟수와 서로 다른 시각을 보존.
- 도착→해석→대상 방→저장 단계, 재노출 억제, 사유별 제외 진단. 기존 알림 조회와 새 callback은 분리 집계.
- 원문 포함 JSONL 및 원문 없는 진단 전용 내보내기, 수집 중지·로컬 삭제. 구조 진단은 최근 100개/72시간 이내로 제한.
- 7일 보관 정리. 앱 시작·화면 갱신·알림 처리 시 수행하며 앱이 강제 종료된 동안 정시 삭제를 보장하지 않는다.

## 설치와 첫 실행

1. 제공된 `kakao-radar-0.3.0-debug.apk`를 서브폰으로 옮겨 설치한다. 개인 테스트용 debug 서명 APK다.
2. 앱에서 **알림 접근 설정 열기**를 눌러 ‘카톡 레이더’의 접근을 허용한다.
3. 대상 카톡방의 알림을 켜고 새 메시지를 기다린다. 소리·진동은 별도로 꺼도 되지만 실제 수집 여부는 확인해야 한다.
4. 앱의 **발견한 방에서 선택**에서 대상 방을 확인하고 **수집 시작**을 누른다.
5. 새 메시지를 몇 개 받은 뒤 저장 건수와 최근 원문을 확인한다. 첫 알림 창에는 카톡이 함께 제공한 이전 메시지가 포함될 수 있다.
6. [실기기 검증 안내](docs/DEVICE_TEST.md)를 따라 화면 꺼짐·재부팅·폭주 구간을 비교한다.

직접 설치한 APK의 알림 접근 메뉴가 제한되는 경우에는 Android가 표시하는 앱 정보의 제한 설정 안내를 확인한다. 기기의 보안 검사를 일괄 해제하거나 보호 기능을 우회하지 않는다. 접근 권한은 사용자가 단말에서 직접 부여해야 한다.

## 현재 한계

현재 실측은 KakaoTalk 26.8.0 / Android 15의 기존 방 알림 3개다. 다른 버전·알림 설정까지 검증한 것은 아니다. 그룹 여부나 안전한 방 식별 조건이 부족하면 사유를 남기고 제외한다. Android 9/10에서는 MessagingStyle 경로는 지원하지만 EXTRA_MESSAGES 직접 복구 경로는 지원하지 않는다. 진단 횟수와 전체 메시지 수집률은 다르다.

알림에 없는 메시지와 사진·파일 본문을 복원할 수 없다. 알림 창이 겹치지 않거나 시각이 없으면 ‘순서 확인 필요’로 표시한다. 동일 내용·발신자·시각·개수의 완전히 동일한 창은 재노출과 새로운 반복을 구별할 수 없다. 이런 플랫폼 정보의 한계까지 100% 수집으로 표현하지 않는다.

shortcut ID가 있으면 같은 ID의 표시 제목·알림 키 변경을 허용한다. 제목이 실제 방 이름임은 선택 시 확인해야 한다. shortcut ID가 없는 경우 정확한 제목과 알림 키를 함께 확인하며 재부팅·카톡 업데이트 뒤 재선택이 필요할 수 있다. 대상 방을 바꾸기 전 기록도 내보내기에 포함되므로 비교 시 room_id로 구분한다.

발신자는 설치별 HMAC 가명으로 저장하지만 대화 원문은 평문으로 앱 전용 저장소에 남는다. Android 백업을 비활성화했으며 별도 DB 암호화는 구현하지 않았다. 내보낸 파일에는 원문이 포함되고, 사용자가 선택한 저장 위치가 클라우드이면 동기화될 수 있다.

## 소스에서 빌드

필요 환경: JDK 17, Android SDK Platform 35 및 Build Tools, Gradle 8.9. 실제 사용 버전은 빌드 설정에 고정되어 있다.

`android` 폴더에서 `gradlew.bat testDebugUnitTest assembleDebug lintDebug`를 실행한다. macOS/Linux는 `./gradlew`를 사용한다. Android Studio에서는 `android` 폴더를 열고 SDK 위치를 지정한다. APK 경로는 `app/build/outputs/apk/debug/app-debug.apk`다.

자동 검사에는 순수 메시지 창 비교 테스트와 Robolectric Android 15 파서·Room 트랜잭션 복구 테스트가 포함된다. 실제 단말 테스트는 USB 디버깅 연결 후 `gradlew.bat connectedDebugAndroidTest`로 실행할 수 있다. 이 명령은 테스트용 DB만 생성·삭제한다.
